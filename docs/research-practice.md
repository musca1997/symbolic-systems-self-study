# 研究实践：从“看过”到“能够独立研究”

[← 首页](../README.md)

## 三个阶段的能力边界

| 阶段 | 核心能力 | 合理产物 |
|---|---|---|
| 本科核心 | 理解方法、完成习题、分析基本证据 | 小型项目、清晰论证、可运行实现 |
| 研究生 | 重建论文、选择模型、识别假设与局限 | 复现报告、研究提案、硕士级研究原型 |
| 博士研究 | 提出有价值且可推进的新问题，接受同行质疑 | 原创论证/定理/方法/证据与明确贡献 |

阶段由研究能力而不是读书数量决定。自学资源不能替代导师反馈、研究共同体、伦理审查或正式学位训练。

## 交叉项目菜单

### 项目 1：有限理性的语言推断

- 组合：形式语义/语用 + 贝叶斯建模 + 心理实验。
- 任务：实现一个最小 Rational Speech Act 模型，与字面理解及启发式基线比较。
- 数据：优先使用许可明确的公开数据或合成数据；真人实验须遵循伦理要求。
- 评估：留出预测、先验敏感性、参数恢复；若两个模型不可区分，明确承认。

### 项目 2：视觉分类中的相关与因果

- 组合：机器学习 + 因果推断 + 科学解释。
- 任务：生成形状与背景相关的数据，在环境变化中比较 ERM 与一个稳健方法。
- 评估：环境划分、独立随机种子、置信区间、失败案例、已知机制与假设。
- 边界：合成数据的成功不等于现实因果发现已解决。

### 项目 3：模型是否利用了句法？

- 组合：语言学 + 神经模型 + 可解释性。
- 任务：最小对测试、结构探针、控制任务与定向干预。
- 评估：泄漏检查、词汇控制、探针容量、干预是否破坏无关信息。
- 边界：探针可解码不等于模型实际使用。

### 项目 4：人机决策与认知分工

- 组合：HCI + 决策论 + 分布式认知。
- 任务：研究 AI 建议在何种任务与呈现方式下帮助或干扰判断。
- 评估：预注册、对照、顺序效应、学习效应、效应量与不确定性。
- 边界：避免高风险医疗/法律场景；未经审批不招募参与者或收集敏感信息。

## 复现的最低标准

- [ ] 记录问题、论文正式版本、代码版本、数据许可。
- [ ] 区分复现原结果与独立数据检验；说明采用的术语。
- [ ] 写清硬件、软件环境、随机种子与运行命令。
- [ ] 先跑简单基线，再跑复杂模型。
- [ ] 不仅复现图形，还核对数据清洗、超参数选择和评价协议。
- [ ] 报告误差条、计算预算、失败运行与偏离原论文之处。
- [ ] 公开前移除个人数据、密钥、受限数据与版权材料。

## 建议的研究仓库结构

```text
project/
├── README.md             # 问题、结果、限制、运行入口
├── environment.yml       # 或 pyproject.toml / 其他锁定环境
├── data/README.md        # 数据来源、授权、获取步骤；不默认上传原始数据
├── src/
├── tests/
├── configs/
├── notebooks/
├── results/              # 可追溯的汇总结果
├── report.md
└── references.bib
```

## 研究提案模板

1. **问题与意义**：为什么不是仅仅扩大数据或模型？
2. **现状与缺口**：哪些结果已知，哪些结论冲突？
3. **竞争假说**：至少两个可能解释，以及区分它们的观察。
4. **方法**：证明、实验、模拟、访谈或混合方法；各自证据标准不同。
5. **有效性**：识别假设、统计功效/精度、模型恢复、外部效度。
6. **开放科学与伦理**：预注册、许可、隐私、数据管理。
7. **可行性**：时间、算力、数据、工具；失败后的缩小版问题。
8. **贡献判据**：什么算成功，什么结果会迫使修改主张？

## 博士级自检：不是资格考试的替代

- 能否说明研究问题的学科归属与跨学科增量？
- 能否把核心定义和假设写到别人可以攻击的精度？
- 是否能清楚陈述最强的反对意见？
- 是否已经检查相关反例、负结果、研究重复与数据泄漏？
- 贡献是新知识，还是仅仅更换工具、数据集与措辞？
- 他人能否检查推导、重跑结果或评估论证？
- 是否有导师、同行或读书会提供独立批评？
